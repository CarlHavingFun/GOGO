## 1. 产品目标

GOGO 的地图不是传统战术射击地图，也不是随机迷宫，而是承载 20 波战斗、角色构筑和持续走位决策的固定大竞技场。

每张竞技场必须同时满足：

1. 玩家可以连续绕怪，不能因为唯一死胡同被地图直接判死；
2. 远程、近战、爆炸、燃烧、烟雾、穿透和控制构筑都有发挥空间；
3. 怪物从合理的门、巷道、隧道或工业通道进入，而不是在玩家面前凭空生成；
4. 地图几何不能制造永久无脑守点或无限绕柱点；
5. 怪物数量、队列和寻路请求有明确性能上限；
6. 地图通过统一接口接入 `SpawnDirector`，禁止为单张地图写硬编码分支；
7. 熟悉战术射击的玩家可以产生空间联想，但不能把地图识别为原地图的像素复刻。

- 为复刻经典地图而牺牲肉鸽走位和原创化。

## 3. 三层空间结构

每张地图必须拆成三层：

```text
┌──────────────────────────────────────┐
│ A. 外围出生缓冲区：玩家不可进入       │
│  ┌────────────────────────────────┐  │
│  │ B. 入场过渡区：门、巷道、隧道    │  │
│  │  ┌──────────────────────────┐  │  │
│  │  │ C. 玩家战斗区             │  │  │
│  │  └──────────────────────────┘  │  │
│  └────────────────────────────────┘  │
└──────────────────────────────────────┘
```

### 3.1 外围出生缓冲区

- 玩家不可进入、不可直接看见生成原点；
- 常规武器射线不能命中缓冲区中的等待怪物；
- 建议宽度为 6～10 个 32 px 地块；
- 负责生成、轻量排队、流量控制和入场路径准备；
- 等待怪物不运行完整战斗 AI、攻击、复杂避障或昂贵目标查询；
- 缓冲区可以在美术上位于城墙背面、深隧道、房屋背街、集装箱后场或铁路远端。

### 3.2 入场过渡区

- 怪物从缓冲区进入战斗区必须经过可解释的入场路径；
- 长度建议为 4～12 个地块；
- 玩家可以看见怪物从过渡区末端出现，但不能看见生成原点；
- 通道必须支持该入口声明的敌人体型；
- 怪物通过 `EntryGate` 后才激活完整战斗逻辑。

### 3.3 玩家战斗区

- 角色、敌人、投射物、赏金、投掷物和事件实际发生的区域；
- 至少形成两条大回环和一条局部绕行路线；
- 不允许只有一个出口的深死胡同，除非它是明确的风险奖励区并存在紧急逃生口；
- 主要区域之间不能全部依赖同一个窄门；
- 地形变化优先服务战斗选择，不追求战术射击原图比例。

## 4. 尺寸、路线与碰撞基线

### 4.1 尺寸建议

- M1 双尘旧城灰盒战斗区：约 60 × 40 个 32 px 地块；
- 正式版本可以扩展到约 72 × 48 个地块；
- 外围缓冲区不计入玩家可活动面积；
- 扩大地图不能明显降低遭遇密度或让近战怪长期无法接触玩家。

### 4.2 必备区域职责

每张地图至少包含：

1. **中央交汇区**：多方向压力汇集，适合通用战斗；
2. **长视野区**：适合 AWP、AK、Deagle、穿透和远程敌人；
3. **压缩区**：适合手雷、燃烧、烟雾和范围伤害；
4. **风险奖励区**：视野或奖励更好，但出口更少；
5. **外围回环**：玩家紧急撤离与重新组织的主要路线。

### 4.3 路线硬规则

- 任意主要区域到另一主要区域至少有两条路线；
- 玩家沿外围移动一周时，不能被迫穿过唯一窄门；
- 宽度小于 3 个地块的通道不能承担主怪物流量；
- 常规入口进入战斗区后，8～12 个地块内至少分叉为两条路线；
- 大型怪至少能够使用 4 个常规入口；
- 不连续摆放多个小障碍形成导航锯齿；
- 地图不能让所有怪物最终汇入同一个 chokepoint。

### 4.4 碰撞规则

- 灰盒使用矩形、圆形或简单多边形碰撞；
- 装饰和碰撞分离；
- 墙体顶部不能遮挡角色、敌人轮廓和危险预警；
- 不实现真实高低差、跌落或蹲伏掩体；
- 正式墙体必须同时阻挡玩家移动和不允许穿透的射线；
- 可穿透材质必须由明确数据配置，不以视觉猜测决定。

## 5. 出生口契约

每张正式地图必须提供：

- 8 个常规入口；
- 2～4 个备用入口；
- 至少 2 个特殊入场点；
- 1 个 Boss 专属入口，或一组明确的 Boss 候选入口；
- 每个常规入口都连接外围缓冲区和独立入场路径。

分布要求：

- 覆盖地图四个主要方向；
- 相邻主要方向之间不能留下超过约 90° 的无入口空白；
- 同一主要区域至少有两个可替换入口；
- 玩家靠近任一入口时，仍应保留至少 5 个合法候选入口；
- 出生口不能与玩家出生点、波间商店、奖励交互点重叠；
- Boss 入场不能封死玩家唯一逃生路线。

### 5.1 `SpawnPortal` 节点结构

```text
SpawnPortal
├── BufferSpawn
├── EntryPath
├── EntryGate
├── VisibilityAnchor
└── DebugLabel
```

职责：

- `BufferSpawn`：缓冲区中的轻量生成与排队位置；
- `EntryPath`：从缓冲区到战斗区的入场路径；
- `EntryGate`：进入完整战斗状态的边界；
- `VisibilityAnchor`：镜头与遮挡检测参考点；
- `DebugLabel`：入口 ID、容量、冷却和拒绝原因。

### 5.2 入口数据字段

```gdscript
class_name SpawnPortal
extends Node2D

@export var portal_id: StringName
@export var kind: PortalKind
@export var sector: StringName
@export var base_weight: float = 1.0
@export var max_buffer_queue: int = 12
@export var max_transition_count: int = 8
@export var max_live_nearby: int = 16
@export var cooldown_sec: float = 2.0
@export var min_player_distance_px: float = 420.0
@export var supported_size_tags: Array[StringName]
@export var supported_enemy_tags: Array[StringName]
@export var pressure_tags: Array[StringName]
```

硬约束：

- `portal_id` 在单张地图中唯一；
- `BufferSpawn` 位于可玩边界外；
- `EntryGate` 位于合法战斗路径上；
- 路径失效时入口直接禁用；
- 容量已满时入口不能继续堆怪；
- 特殊入口必须拥有 0.7～1.2 秒可读预警。

## 6. 数据与运行职责边界

### 6.1 `ArenaDefinition`

静态 `Resource`，只保存地图身份和稳定配置：

```gdscript
class_name ArenaDefinition
extends Resource

@export var id: StringName
@export var display_name: String
@export var scene_path: String
@export var release_status: ArenaReleaseStatus
@export var tags: Array[StringName]
@export var supported_enemy_size_tags: Array[StringName]
@export var recommended_camera_profile_id: StringName
@export var performance_profile_id: StringName
```

不在 `ArenaDefinition` 中保存运行时队列、玩家位置、入口冷却或当前压力。

### 6.2 `ArenaRoot`

场景根节点负责提供地图查询接口：

```gdscript
func get_playable_bounds() -> Rect2
func get_player_spawn() -> Marker2D
func get_spawn_portals(kind: int) -> Array[SpawnPortal]
func get_event_slots(tag: StringName) -> Array[Node2D]
func validate_contract() -> PackedStringArray
```

场景树建议：

```text
ArenaRoot
├── Navigation
├── Geometry
├── SpawnPortals
│   ├── Regular
│   ├── Reserve
│   ├── Special
│   └── Boss
├── EventSlots
├── PlayerSpawn
├── SettlementSlots
├── Boundary
└── DebugOverlay
```

### 6.3 `WaveSpawnProfile`

`06_怪物与波次设计.md` 中原称 `SpawnProfile` 的波次层配置，在实现中统一命名为 `WaveSpawnProfile`，负责：

- 威胁预算；
- 活跃敌人上限；
- 敌人权重；
- 职责最低与最高配额；
- 精英规则；
- 批次间隔；
- 波次主题方向权重；
- 安全距离默认值。

它不保存具体地图节点或某张地图的入口 ID。

### 6.4 `SpawnDirector`

负责组合：

```text
WaveSpawnProfile
+ ArenaRoot 提供的入口快照
+ 玩家位置与镜头
+ 当前入口队列和拥堵
+ 当前危险区
+ spawn_rng
```

`SpawnDirector` 不通过地图 ID 判断行为；地图差异全部通过入口、区域标签和数据表达。

### 6.5 `SpawnCandidateSelector`

纯逻辑类，输入候选快照和独立随机流，输出入口 ID 或延后结果。它不直接访问场景树，便于固定种子回归。

建议接口：

```gdscript
func choose(
    candidates: Array[SpawnPortalSnapshot],
    context: SpawnSelectionContext,
    rng: RandomNumberGenerator
) -> SpawnSelectionResult
```

## 7. 刷怪循环

```text
读取 WaveSpawnProfile
    ↓
计算当前预算与职责缺口
    ↓
从 ArenaRoot 获取候选入口快照
    ↓
过滤距离、镜头、路径、容量、冷却和危险区
    ↓
计算入口评分
    ↓
使用 spawn_rng 选择入口
    ↓
在 BufferSpawn 创建轻量等待实体
    ↓
沿 EntryPath 进入
    ↓
穿过 EntryGate 后激活完整战斗逻辑
    ↓
记录成功、延后、拥堵和入口使用率
```

若无合法入口：

1. 尝试其他方位；
2. 缩小本批数量；
3. 延后 0.25 秒；
4. 保留预算但限制最多积累两个生成周期；
5. 绝不贴脸强制生成。

## 8. 入口过滤和评分

### 8.1 硬过滤

入口出现以下任一情况时不得进入评分：

- 距玩家小于本入口安全距离；
- 生成原点或 `EntryGate` 位于镜头中心安全矩形内；
- 入场路径无效；
- 缓冲队列、过渡区或入口附近密度已满；
- 入口处于冷却；
- 与 Boss、障碍或高伤害预警重叠；
- 不支持本批敌人体型或标签；
- 冲锋怪没有足够完整前摇距离。

### 8.2 推荐评分

```text
入口分数 =
基础权重
+ 距离处于理想区间
+ 不在当前镜头内
+ 当前方位压力不足
+ 与上一批入口不同
+ 本波主题入口
+ 玩家长时间停留区域的侧后方压力
- 玩家正面对准入口
- 入口附近拥堵
- 最近连续使用
- 入场耗时过长
```

距离建议：

- 小于 420 px：常规入口禁用；
- 420～640 px：只在有足够遮挡和前摇时使用；
- 640～1024 px：常规理想距离；
- 更远：允许使用，但必须评估进入战斗所需时间。

### 8.3 活跃入口组

- 常规波同时激活 4～6 个入口；
- 其中 2 个为主压力口，2 个为辅助压力口；
- 每 8～15 秒重新评估；
- 单个入口最多连续承担两批主压力；
- 所有入口不能完全平均撒怪，必须形成可读的主次方向。

## 9. 拥堵与反守点

每个入口分别限制：

1. 缓冲队列容量；
2. 过渡区容量；
3. 入口附近活跃敌人上限。

任一容量触发后：

- 暂停该入口；
- 把预算切换到其他入口；
- 必要时启用已预警的特殊入场点；
- 不让怪物在门后无限堆积等待范围伤害收割。

反守点按温和顺序处理：

1. 提高侧面和背后入口权重；
2. 增加已有波次配置中的远程、推进、越障或封区职责；
3. 启用钻地、屋顶、通风口或墙体破口等特殊入场；
4. 仍保留明确预警和可逃路线。

禁止：

- 无预警生成在玩家脚下；
- 因玩家守点而直接提高全体血量；
- 无提示关闭玩家身后出口；
- 根据玩家构筑生成免疫怪；
- 让入口选择持续追踪玩家精确位置而形成作弊感。

## 10. Boss 与特殊入口

### 特殊入口

- 必须显示 0.7～1.2 秒预警；
- 预警形状不能被烟雾完全遮蔽；
- 声音和动画必须能说明来源；
- 同一特殊入口不能连续高频使用；
- 每个特殊入口声明可支持的敌人类型。

### Boss 入口

- 与普通入口分离；
- 入场演出不能立即造成无提示伤害；
- 不封死唯一回环；
- Boss 进入后增援仍由普通入口系统调度；
- 动态破坏在 M1 只做演出占位，不改变导航拓扑。

## 11. 地图对生成系统的反向要求

新地图在接入前必须通过：

### 出生结构

- 8 个常规入口；
- 至少 2 个特殊入口；
- 1 个 Boss 入口；
- 所有常规入口连接独立外围缓冲区。

### 路径质量

- 每个入口拥有有效入场路径；
- 进入战斗区后 8～12 格内分叉；
- 大型怪至少能使用 4 个入口；
- 不存在全部敌人必经的唯一窄门。

### 安全与可读性

- 生成原点不在玩家可达区；
- 常规生成原点不进入镜头；
- 玩家接近任一入口后仍有至少 5 个替代入口；
- 所有特殊入口和 Boss 入场拥有可读预警。

### 性能

- 缓冲区等待怪物使用轻量状态；
- 超过容量的请求延迟或转移；
- 入口切换不反复创建无效导航请求；
- 入口路径不存在持续碰撞抖动。

地图不满足这些条件时，优先修改地图；禁止在 `SpawnDirector` 中增加 `if arena_id == ...` 特例。

## 12. 遥测与调试

必须记录：

- 每个入口使用次数和预算占比；
- 平均与最大缓冲队列长度；
- 拥堵触发次数和持续时间；
- 被距离、镜头、导航、容量、冷却拒绝的次数；
- 玩家各区域停留时间；
- 被包围死亡位置热图；
- 怪物寻路失败和卡死次数；
- 同屏怪物峰值、帧时间和对象池占用；
- 固定种子下的入口选择序列。

初始告警阈值：

- 常规入口长期使用率低于 5%：检查位置、路径或权重；
- 单一常规入口长期高于 25%：检查地图是否依赖单一路线；
- 玩家堵门后 2 秒内没有压力方向切换：失败；
- 怪物卡死率超过总生成量 0.5%：失败；
- 无合法入口导致预算积压超过两个生成周期：失败。

调试覆盖层必须显示：

```text
spawn_attempt
candidate_portal
rejected_too_close
rejected_visible_center
rejected_navigation
rejected_capacity
rejected_cooldown
spawn_deferred
spawn_success
```

## 13. Arena 契约自动测试

每张进入实现阶段的地图必须验证：

- 常规入口不少于 8；
- 特殊入口不少于 2；
- Boss 入口数量符合配置；
- 所有入口 ID 唯一；
- `BufferSpawn` 在可玩边界外；
- `EntryGate` 在有效战斗路径上；
- 每个常规入口拥有有效路径；
- 至少 4 个入口支持大型怪；
- 玩家出生点不与入口重叠；
- 同一种子和候选快照产生同一入口序列；
- 无合法入口返回延后，不强行选择；
- 过近、可见、拥堵、冷却和无路径入口不会被选中。

## 14. 开发顺序

### M0｜AK 射击玩具

- 不实现完整刷怪系统；
- 只把现有竞技场从 `M0RunRoot` 抽成可替换的 Arena 场景；
- 保持现有 `Player`、`TargetDummy` 和 `HUD` 节点路径；
- 让 Arena 提供玩家边界；
- 为未来墙体增加 `World` 碰撞层；
- 保持现有射击测试通过。

### M1｜五波闭环与双尘旧城灰盒

- 双尘旧城灰盒；
- 外围出生缓冲网络；
- 8 个常规入口；
- 2 个特殊入口占位；
- 1 个 Boss 入口占位；
- `ArenaRoot`、`SpawnPortal`、`SpawnDirector`、`SpawnCandidateSelector`；
- 三种基础敌人；
- Wave 1～5；
- 入口使用率、拥堵和固定种子回归。

### M2｜角色与战术验证

- 验证烟雾、背身机制和地图入口预警共存；
- 不增加第二张正式地图。

### M3｜十波垂直切片

- 双尘旧城首轮正式像素素材；
- 完整入口遮挡、环境音和危险事件插槽；
- 小 Boss 入场演出；
- 十波压力和可读性测试。

### M4 以后

- 完成 20 波与最终 Boss 后，才评估赤瓦小镇或货运枢纽；
- 每次只立项一张新地图；
- 新地图必须复用同一 Arena 与 Spawn 契约。

## 15. 竞技场美术边界

遵守 `13_素材生产管线与提示词.md` 和 `14_像素美术Style_Bible.md`：

- 地面 Tile、边界墙、拱门、入口遮挡、掩体、Decal、环境动画分别生产；
- 完整竞技场概念图只用于布局参考；
- 不把一张不可编辑的大图作为最终关卡；
- 地面低对比，角色、敌人、子弹、赏金和危险预警优先；
- 统一 64 × 64 场景地块、俯视 3/4 和左上光；
- 不复制原地图雷达轮廓、标识、涂鸦、贴图、箱体排列或专有名称。

第一张地图的正式资产在进入生产前使用地图专属稳定 ID，例如：

```text
arena_double_dust_floor_variant_01

arena_double_dust_wall_corner
arena_double_dust_arch_gate
arena_double_dust_spawn_gate_dark
arena_double_dust_cover_crate
arena_double_dust_sandbag
arena_double_dust_decal_crack
```

赤瓦小镇和货运枢纽在立项前不批量登记正式素材。

## 17. 可验证的完成标准

- 地图和波次配置职责没有重叠；
- `WaveSpawnProfile` 不保存具体地图节点；

- 固定种子能够重现入口选择；
