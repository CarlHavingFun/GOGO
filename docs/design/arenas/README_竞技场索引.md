## 实现原则

1. 第一版只实现双尘旧城；
2. 新地图必须复用 `ArenaRoot`、`SpawnPortal`、`SpawnDirector` 与 Arena 契约测试；
3. 不为单张地图在刷怪代码中增加硬编码特例；
4. 地图先完成灰盒、缓冲区、入口、导航和压力测试，再生产正式素材；
5. 三张地图使用熟悉的空间语言，但不得复制经典地图的路线比例、雷达轮廓、标识、纹理或资产排列。
