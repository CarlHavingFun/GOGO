## 1. 地图定位

- 玩家联想：沙漠经典地图的长街、中门、隧道与高台。
- 正式名称：双尘旧城。
- 内部代号：`arena_double_dust`。
- 战斗定位：三张地图中的平衡基准图。
- 优势流派：步枪、狙击、沙鹰、手雷、烟雾均有表现空间。

目标是让玩家第一眼感到熟悉，但无法与任何原地图轮廓一一重合。

## 2. 战斗区结构

```text
                         [北侧高台]
                         奖励 / 精英
                              │
                       N1 破损坡门
                              │
 [W1 隧道深处]──[坍塌隧道]──[中门广场]──[沙漠长街]──[E1 长街远门]
       │               │          │               │
 [W2 地下拱道]     [西侧回环]  [南侧回环]      [E2 城墙缺口]
       │               │          │               │
       └──────────[南侧仓院 / 出生区]──────────────┘
                          │          │
                     S1 南拱门    S2 沙坑洞口
```

核心路线：

- 中门广场负责四向交汇。
- 沙漠长街提供最长视野。
- 坍塌隧道提供范围伤害价值。
- 北侧高台是风险奖励区。
- 南侧仓院连接外围回环，防止地图成为三条死路。

## 3. 外围缓冲区

缓冲区环绕整张地图，但在美术上被表现为：

- 城墙背面。
- 黑暗隧道更深处。
- 不可到达的旧城区街巷。
- 沙丘与仓库围墙外侧。

宽度建议：

- 长街方向 8—10 格。
- 隧道方向 6—8 格。
- 南侧仓院 6 格。
- 北侧高台 6—8 格。

所有缓冲区通过不可见导航路线与入口相连，玩家攻击不能穿透到生成原点。

## 5. 特殊入场点

### X1 沙地钻出区

- 位于中门广场外缘和南侧仓院。
- 先显示沙地隆起 0.9 秒。
- 只允许小型怪和特定精英使用。

### X2 城墙翻越区

- 位于长街与中门之间的低墙。
- 怪物出现前墙后先出现阴影或手部轮廓。
- 适合跳跃怪，不能让大型怪使用。

## 6. Boss 入场口

Boss 从长街尽头的封闭远门进入：

1. 地面出现震动和沙尘。
2. 远门产生裂纹。
3. Boss 撞开外层门板。
4. 玩家仍可通过南侧回环和中门侧路撤离。

M1 灰盒只播放门口扬尘和 Boss 入场占位，不实现动态墙体破坏。

## 7. 区域玩法

### 中门广场

- 四向压力最高。
- 适合通用步枪和高速移动。
- 通过两根宽石柱提供绕行，但不允许无限绕柱无伤。

### 沙漠长街

- AWP、AK、沙鹰优势区。
- 侧面城墙缺口和沙坑怪避免长时间站桩。
- 不设置连续小箱体，保持弹道和怪物路径清晰。

### 坍塌隧道

- 手雷、燃烧和烟雾流派优势区。
- 屋顶破洞提供光柱，保证可读性。
- 两个出口连接中门与西侧回环。

### 北侧高台

- 每隔若干波提供补给或精英奖励。
- 视野好但只有坡道与后巷两个出口。
- 玩家停留过久时，提高 N2 和 W2 的权重。

### 南侧仓院

- 波间商店或角色选择的视觉承载区域。
- 战斗中不是绝对安全区，S1、S2 和 B1 都可进怪。

## 8. 20 波地图压力主题

| 波次 | 地图事件 |
|---|---|
| 1—3 | S1、E1、W1 建立三方向认知 |
| 4—5 | 开启 E2 和 W2，首次侧压 |
| 6—8 | 长街沙尘短暂出现，远程怪增加 |
| 9 | 隧道高密度近战波 |
| 10 | 北侧高台精英入场 |
| 11—13 | 钻地怪首次进入中门外缘 |
| 14—15 | 长街与隧道压力交替 |
| 16—18 | 6 个入口轮换，仓院不再安全 |
| 19 | 全地图高压，但保留一侧低压缺口 |
| 20 | 长街 Boss 入场，普通怪从南北两侧增援 |

## 9. 分阶段素材范围

M1 灰盒和首轮像素皮肤：

- 沙土地面 3 种变体。
- 黄色石墙直线、转角、断墙。
- 原创双扇远门。
- 隧道墙体与破洞光斑。
- 木箱、沙袋、陶罐、布棚。
- 高台、坡道和坑边。
- 8 个入口的暗部或遮挡表现。

M3 之后再评估：

- 动态沙尘暴。
- 可破坏墙体。
- 多阶段昼夜。
- 复杂环境动画。
- 区域 Buff。

## 10. 地图验收

- 玩家能沿外围持续绕行一周。
- AWP 在长街有优势，但会受到 E2 和 X2 侧压。
- 燃烧弹在隧道有效，但怪物能通过 W2 分流。
- 任意入口被玩家接近后仍有至少 5 个入口可用。
- 大型怪可从 N1、E1、S1、B1 进入。
- 中门不会成为所有怪物的唯一必经点。
