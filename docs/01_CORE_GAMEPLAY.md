# GOGO 核心玩法设计

## 游戏类型
像素 FPS 肉鸽生存游戏。

参考方向：
- Brotato 的 20 波循环
- FPS 枪械手感
- Roguelike Build 成长

## 核心循环

1. 选择角色
2. 选择初始武器
3. 战斗获取经验金币
4. 波间随机升级
5. 调整 Build
6. 挑战精英与 Boss

## 20波节奏

Wave 1-5:
教学阶段，让玩家理解武器和移动。

Wave 6-10:
加入特殊敌人，迫使玩家选择流派。

Wave 11-15:
精英敌人出现，测试 Build 强度。

Wave 16-19:
高压生存。

Wave 20:
Boss 战。

## 肉鸽原则
每次运行必须存在不同路线：
- 武器路线
- 角色路线
- 道具路线
- 状态路线

避免唯一最优解。
