# GOGO 角色系统设计

## 设计原则
角色不是简单属性差异，而是改变游戏规则。

## 尼尼
定位：精准射击专家

优势：
- 爆头收益提高

负面：
- 敌人可能使用背身诱导，降低命中稳定性

核心Build：
沙鹰、AWP、暴击。

## 小洞大人
定位：高速输出

优势：
- 连杀成长

负面：
- 防御能力较低

核心Build：
AK、射速、移动。

## 设备
定位：狙击大师

优势：
- AWP强化

负面：
- 被稀有武器诱惑，随机事件影响选择

核心Build：
AWP、穿透、精准。

## 上帝
定位：经济运营

优势：
- 金币收益增加

负面：
- 伤害成长较慢

核心Build：
经济、强化。

## 大表哥
定位：烟雾控制

优势：
- 烟雾相关能力增强

负面：
- 离开烟雾区域能力下降

核心Build：
烟雾弹、燃烧弹、区域控制。
