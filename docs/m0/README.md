# M0｜AK 射击玩具

这是 `foundation/topdown-kit-evaluation` 的灰盒验证场景，只验证射击底座，不代表完整 20 波游戏。

## 启动

使用 Godot 4.7.1 stable 打开仓库根目录，运行主场景；或执行：

```bash
godot --path . --editor
godot --path .
```

## 操作

- `WASD`：移动；
- 鼠标：手动瞄准；
- 按住鼠标左键：按 8.5 发/秒持续射击；
- `R`：手动换弹；
- `T`：把散布随机流重置到固定种子 `424242`。

## 可观察内容

- AK 前几发较准，连续射击后准星扩张；
- 停火后后坐力按 38/秒恢复；
- 移动时散布额外增加；
- 弹匣为 30 发，空仓自动换弹，换弹时间 2.2 秒；
- 弹匣非空时射击可取消换弹，且不会凭空补弹；
- 射线、曳光和命中位置使用同一条实际方向；
- 假人 120 HP，单发 24 伤害，5 发击杀，1 秒后复活；
- HUD 显示 FPS、种子、弹药、换弹、后坐力和当前散布。

## 自动测试

```bash
godot --headless --path . --editor --quit
godot --headless --path . res://tests/test_runner.tscn
```

覆盖弹匣、射速冷却、换弹完成、换弹取消、空仓规则、固定种子散布和主场景加载。

## 手动验收清单

- [ ] 连续运行 10 分钟无脚本错误；
- [ ] WASD 八方向速度归一化且不会离开竞技场；
- [ ] 鼠标位置决定角色和真实射线方向；
- [ ] 点射与长扫的准星和命中稳定性明显不同；
- [ ] 第 30 发后进入自动换弹，换弹完成恢复 30 发；
- [ ] 非空换弹可由射击取消，空仓换弹不可取消；
- [ ] 5 发命中击杀假人，1 秒后假人复活；
- [ ] 按 `T` 后相同输入序列可复现散布序列。

## 已知限制

- 没有敌人 AI、波次、升级、商店、角色天赋或投掷物；
- 只有程序生成的灰盒图形，没有正式美术与音频；
- 自动测试验证规则和场景加载，但 10 分钟手感与 FPS 仍需在 Windows 真机人工验收。
