# GOGO AI素材生成规范

## 总原则
所有素材必须保持统一像素风格。

## 角色Prompt方向
pixel art roguelike FPS character, top down view, 16 bit style, game sprite, transparent background

## 武器Prompt方向
pixel art weapon sprite, top down, isolated asset, game item

## 素材拆分
角色、武器、特效必须独立。

禁止生成角色和武器绑定图片。

## 动画
每个角色需要：
- idle
- walk
- shoot
- hurt
- skill

方便Godot动态组合。
